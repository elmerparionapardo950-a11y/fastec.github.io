IMPORTANTE PARA PUBLICACIÓN REAL:
Esta versión usa localStorage para los datos y sessionStorage para la sesión del panel. La contraseña está dentro de JavaScript, por lo que NO debe considerarse una autenticación de servidor segura.
Para una seguridad real en un sitio público, se recomienda mover la autenticación a un backend y proteger la contraseña mediante variables de entorno o un sistema de usuarios.
